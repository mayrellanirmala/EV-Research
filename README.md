# 72V Plug-in Hybrid EV Power System

Ongoing undergraduate EV research project focused on developing a 72V electrical power system architecture for hybrid vehicle applications.

## Project Scope
- HV-LV power distribution
- Power subsystem integration
- Electrical safety implementation
- Hybrid EV system architecture

## Integrated Subsystems
- Battery Management System (BMS)
- Motor Controller Unit (MCU)
- DC-DC Converter
- On-Board Charger (OBC)
- Power Distribution Unit (PDU)

## Tools Used
- MATLAB/Simulink
- AutoCAD Electrical

## Current Progress
- Initial electrical architecture development
- Subsystem integration planning
- Safety and protection system study
